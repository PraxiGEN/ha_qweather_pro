# 使用指南 (Documentation)

适用于和风天气 Pro 2.0.0 及以上版本。最低 Home Assistant 版本：**2026.9.0**。

## 配置模型

2.0.0 以 1.3.x 引入的子条目结构为唯一结构：

- 1 个**账号条目**仅保存 API Host 与凭据。
- 每个城市是该账号下的 1 个**位置子条目**，各自持有预报步长、刷新间隔与 UI 开关。
- 凭据只需填写一次。新增城市在账号条目页完成；修改某个城市通过对应子条目的「配置」。
- 账号凭据在主条目用「重新配置」修改；位置选项在子条目用「配置」修改。

## ⚙️ 配置

### 1. 获取和风天气凭据

前往[和风天气控制台](https://console.qweather.com)：

- **JWT（推荐，默认）**：在项目中添加 JSON Web Token 凭据。
  - 项目 ID（Project ID）与凭据 ID（Key ID）：在对应项目的详情页查看。
  - 开发者 ID（Iss）：在**控制台-设置**中查看，Q 开头的 10 位字母/数字。
- **API KEY**：获取普通的 API KEY。和风天气将限制 API KEY 请求且 SDK 5+ 不再支持，因此该模式下集成强制 100 分钟刷新间隔。
- 获取个人专属 **API Host**。

### 2. 添加账号与首个城市

1. 进入**设置 > 设备与服务 > 添加集成**，搜索 **QWeather Pro**。
2. 填写：
   - **API 服务器地址（Host）**：个人 API Host。
   - **地理位置**：默认取 HA 的经纬度；城市名、城市 ID（仅支持中国区域）或 `经度,纬度` 也可识别。
   - **使用 JWT**：默认开启。仅在使用 API KEY 时关闭。
   - **API KEY**：关闭 JWT 时必填。
3. JWT 模式下，下一步会显示生成的**公钥**及 SHA256 指纹：
   - 将公钥填入和风天气控制台的 JWT 凭据设置。
   - 在 HA 中填写项目 ID（Project ID）、凭据 ID（Key ID）与开发者 ID（Iss）。
   - 私钥在本地生成并保存，界面只展示公钥。
4. 从搜索结果中选择城市。完成后即创建账号条目及其首个位置子条目。

### 3. 新增或修改位置子条目

- 在**设置 > 设备与服务**中打开 QWeather Pro 条目，通过位置子条目入口添加其他城市；搜索后从结果中选择，重复位置会被拒绝。
- 打开某个位置子条目，选择**配置**可修改：
  - 刷新间隔：5–1440 分钟（仅 JWT；API KEY 固定 100 分钟，不显示该控件）。
  - 逐日预报天数：3 / 7 / 10 天。
  - 逐小时预报小时数：24 / 72 / 168 小时。
  - 启用自定义前端 UI 支持（`custom_ui`）。
  - 覆盖原生详情弹窗（`custom_more_info`）。
- 位置本身不可编辑。需要更换城市时，请删除该子条目后重新添加。

### 4. 重新配置账号（主条目）

在**设置 > 设备与服务**中打开 QWeather Pro 账号条目，选择**重新配置**可修改账号级设置。此处**不修改位置**；位置选项请到对应子条目的「配置」中修改。

可修改项：

- **API 服务器地址（Host）**：更换个人专属 API Host。
- **鉴权方式**：在 JWT 与 API KEY 之间切换。
  - 切到 JWT 且已有密钥对时，可选择**保留原配置（复用密钥对）**（沿用现有项目 ID、凭据 ID、开发者 ID（Iss）与私钥，无需改动控制台），或**重新生成 JWT（新密钥对）**（需将新公钥重新填入和风天气控制台）。
  - 从 API KEY 首次切到 JWT 时，直接生成新密钥对并按提示完成 JWT 配置。
  - 切回 API KEY 时，自动清除已保存的 JWT 凭据，避免旧私钥残留。
- **API KEY**：关闭 JWT 时必填；该模式下刷新间隔锁定为 100 分钟。

提交时，集成会用**首个位置子条目的坐标**验证凭据；变更对账号下**所有位置**生效，验证通过后自动重载。若 JWT 认证失败，会引导重新填写 JWT 参数。

## 📈 前端展示

只有当至少一个位置开启了 `custom_ui` 或 `custom_more_info` 时，前端资源才会注册。开启开关后按 Home Assistant 提示重载或重启，再在 Lovelace 仪表盘添加卡片：

```yaml
type: custom:qweather-pro-card
entity: weather.qweather_pro_<城市名>_weather
```

请将 `<城市名>` 替换为该位置实际生成的实体 ID。卡片支持列表 / 曲线两种样式、7 日与 24 小时预报切换，以及逐小时图的滚轮缩放与平移。

## 天气数据服务

在「开发者工具 > 动作」中调用 `qweather_pro.get_weather`，可从天气实体、设备或区域获取完整数据。使用 `keys` 限制返回的数据块：

```yaml
action: qweather_pro.get_weather
target:
  entity_id: weather.qweather_pro_<城市名>_weather
data:
  keys:
    - aqi
    - warning
```

可用 keys：`city`、`now`、`daily`、`hourly`、`aqi`、`warning`、`indices`、`weather_abstract`、`minutely_detail`、`minutely_summary`、`update_time`、`attributions`。省略 `keys` 时返回全部数据。

## 从 1.x 升级

**[ACTION REQUIRED]** 1.2.x 不能直达 2.0.0。

| 从 -> 到 | 结果 |
|---|---|
| 1.3.x -> 2.0.0 | HA 2026.9.0+ 可直接升级 |
| 1.2.x -> 1.3.x | 自动迁移为账号条目 + 位置子条目 |
| 1.2.x -> 2.0.0 | 不支持；请先安装 1.3.x |
| 1.3.x+ -> 1.2.x | 不支持；v2 数据无法回退 |

若 2.0.0 加载到 v1 条目，设置会失败，并生成说明两步升级路径的持久「修复」条目。
