### 🛠 v2.0.0 - 架构精简与最低 HA 2026.9.0

本版本是 **2.x 系列的首个版本**：移除 1.x 迁移层，只保留 1.3.x 引入的子条目架构，并把最低 Home Assistant 版本提升至 2026.9.0。本版只做减法，不新增用户可见功能。

> ⚠️ **破坏性变更（升级前必读）**
>
> - **低于 2026.9.0 不支持升级 / 安装**：2.0.0 的最低支持版本为 Home Assistant 2026.9.0，由 HACS 在市场层直接拦截，请勿在旧版本上手动替换文件。
> - **不支持从 1.2.x 直接升级**：2.0.0 已删除 v1 → v2 迁移层。1.2.x 用户必须先升级到 1.3.x 完成自动迁移，再升级到 2.0.0。
> - **v1 条目会被拒绝**：若 2.0.0 加载到未迁移的 v1 条目，设置会失败，并生成持久的 `legacy_entry`「修复」条目指向下述升级路径。
> - **无法回退**：1.3.x / 2.0.x 的 v2 条目数据不能降级回 1.2.x。

#### ⚠️ 升级路径

| 从 -> 到 | 结果 |
|---|---|
| 1.3.x -> 2.0.0 | HA 2026.9.0+ 可直接升级 |
| 1.2.x -> 1.3.x | 自动迁移为账号条目 + 位置子条目 |
| 1.2.x -> 2.0.0 | 不支持；请先升级 1.3.x 完成迁移，再升级 2.0.0 |
| 1.3.x+ -> 1.2.x | 不支持；v2 条目数据无法回退 |

#### 🔧 主要变更

- **删除迁移层**：移除 v1 条目自动迁移代码与兼容分支，位置处理改用原生 `get_subentries_of_type`。
- **Schema 迁移**：配置流与服务 schema 从 voluptuous 迁移到 HA 核心校验库 probatio；CI 同步移除 voluptuous 依赖。
- **HA API 更新**：HA 2026.11+ 使用 `async_unload_platforms_or_raise`；HA 2026.12+ 使用 `UpdateFailedUnreachable`（旧版本保留回退）。
- **问题修复**：HA 2026.10+ 上配置成功弹窗改用集成自身的翻译，不再显示 Home Assistant 的英文回退文案。
- **元数据**：`hacs.json` 移除 `render_readme`，保留 `zip_release`；最低 HA 由市场声明为 2026.9.0。

### 🛠 v1.3.0 - 子条目架构

1.x 系列收官版本，也是 2.0.0 的基座。

- 1 条目 = 1 账号（仅凭据）+ 每城市 1 个位置子条目。预报步长、刷新间隔与自定义 UI 选项下沉至各位置子条目。
- 存量条目首次启动自动迁移，实体、设备与历史数据原样保留；同 host 条目自动合并，JWT 优先。
- 迁移单向：迁移后无法回退 1.2.x，需卸载后重新配置。
- 支持 HA 2026.1.0+；推荐 2026.5.0+ 以使用原生子条目 API。

### 🛠 v1.2.6 - 1.2.x 稳定基线

1.2 系列首个稳定版，由 1.2.0-beta 系列收敛而来。

- 数据层从和风天气 V7 迁移至 V1，预报改为 `daytime` / `nighttime` 嵌套结构，并新增主备 API Host 回退；引用旧 V7 属性的模板需更新。
- JWT (EdDSA) 成为默认鉴权；API KEY 仍可用，但刷新间隔被强制锁定为 100 分钟。
- 仪表盘卡片重写为零依赖原生 SVG，消除全局 ApexCharts 冲突。
- 前端资源注入改为 opt-in，由 `custom_ui` 与 `custom_more_info` 两个独立开关控制。
- 字符串型 `temp_range` 传感器更名为数值型 `current_temperature`。
- 新增 `qweather_pro.get_weather` 服务、诊断信息脱敏、重新认证流程、持久化天气缓存与 12 语言翻译。

### 🛠 v1.1.0 - 全链路国际化与容错

- 系统语言同步至和风天气 API（30+ 种语言）；分钟级降水与生活指数按规则回退英文。
- 适配和风天气个人 API Host 强制要求以及 GeoAPI 路径变更。
- 引入 Tenacity 指数退避重试、智能退让模式与冷启动自愈。
- 城市名 / 城市 ID / 经纬度输入统一标准化为坐标后请求 API。
- AQI 与预警升级至 V1 数据，提供站点级污染物浓度与完整预警字段。
- 采用 `ConfigEntry.runtime_data` 与 PEP 695 类型别名。
